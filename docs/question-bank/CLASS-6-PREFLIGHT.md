## Import and quality gates

1. Obtain a secure least-privilege database connection in the execution environment; never paste credentials in chat or commit them. Authorization alone does not configure access.
2. Confirm current Class 6 book PDFs/edition and contents; preserve original source/page references for review. Do not silently rewrite selectors.
3. Read-only count existing approved/pending MCQs by category, subject, topic; identify exact/near duplicates and gaps. Do not delete existing records.
4. Prepare source-grounded original draft questions; record four distinct options, exactly one supported answer, explanation and source/page (or reproducible arithmetic verification). Separate structural checks from subject-matter review; automated validation alone cannot prove correctness.
5. Pilot one verified chapter, review answers and ambiguity before publication. Insert pending drafts first; use a transactional, idempotent batch and record inserted IDs for batch-specific rollback. Do not rely on createMany skipDuplicates: Question has no content uniqueness constraint.
6. Publish only reviewed questions and check creator/practice visibility using existing permissions. Student remains exam/practice-only. Report actual inserted/approved counts per batch.
