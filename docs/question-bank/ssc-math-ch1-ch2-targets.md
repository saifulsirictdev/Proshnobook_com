## উৎস ও সীমাবদ্ধতা

- প্রথম অধ্যায়ের আগের ৯টি MCQ এবং দ্বিতীয় অধ্যায়ের আগের ২টি MCQ + ২টি CQ অপরিবর্তিত রাখা হয়েছে। এগুলোর বোর্ড/সাল/প্রশ্ন/মুদ্রিত পৃষ্ঠা/PDF পৃষ্ঠা সংরক্ষিত। বোর্ডের পরিচয় সংকলনের শিরোনামভিত্তিক; মূল সরকারি প্রশ্নপত্রের স্বাধীন authentication নয়।
- অবশিষ্ট **৭৪৭টি নতুন নিজস্ব অনুশীলনী**: ৪৮৯ MCQ + ১৪৮ CQ + ১১০ SQ। এগুলোকে বোর্ডের প্রশ্ন বা NCTB বইয়ের অবিকল অনুশীলনী বলা হয়নি। প্রতিটির `page`-এ নিজস্ব অনুশীলনী লেখা এবং validation-এ origin/family/variant আছে।
- একেক দক্ষতার একাধিক সংখ্যাভিত্তিক variant আছে। এগুলো ৭৬০টি ভিন্ন ধারণা নয়। প্রথম অধ্যায়ে নতুন MCQ/CQ/SQ যথাক্রমে ২৪/১০/১০টি সমস্যা-পরিবার থেকে, দ্বিতীয় অধ্যায়ে ৩০/১৪/১৪টি থেকে তৈরি।
- সম্পূর্ণ বোর্ড সংগ্রহ অনুসন্ধান ও প্রতিটি প্রশ্নের chapter audit শেষ হয়নি। NCTB বইয়ের সম্পূর্ণ অধ্যায়/চলতি সংস্করণ পড়া সম্ভব হয়নি। তাই **বোর্ড→NCTB→ইন্টারনেট উৎসে সম্পূর্ণ অনুসন্ধান শেষ হওয়ার দাবি নয়**; সংখ্যাগত লক্ষ্য নিজস্ব practice দিয়ে পূর্ণ হয়েছে।
- তৃতীয়পক্ষের [অধ্যায়সূচি](https://pi-mathematics.blogspot.com/2022/10/ssc9-10-general-math-solution.html) থেকে বিষয়সীমা মিলেছে; সংযুক্ত exercise পৃষ্ঠাগুলো usable প্রশ্নের body দেয়নি। সেখান থেকে প্রশ্ন কপি করা হয়নি।
- CQ-তে তিনটি অংশ, নম্বর **২–৪–৪**, প্রতিটি অংশের সমাধান আছে। SQ-তে উত্তর/ব্যাখ্যা ও MCQ-তে চারটি বিকল্প, key এবং ব্যাখ্যা আছে।
- সাইটের বর্তমান catalog অনুযায়ী scope `Class 9 / গণিত`; অধ্যায়ের নাম যথাক্রমে `১ম অধ্যায়: বাস্তব সংখ্যা` এবং `২য় অধ্যায়: সেট ও ফাংশন`। SSC নবম–দশমের একই বিষয়বস্তু বলে Class 10-এ আবার কপি করে সংখ্যা বাড়ানো হয়নি।

## পরীক্ষা

- ৫টি batch strict importer-এ উত্তীর্ণ; প্রতিটি সর্বোচ্চ ২০০ item ও ৭৫০ KB-এর নিচে।
- অধ্যায়জুড়ে normalized stem-এ একই প্রশ্ন নেই; seed-গুলো একবারই আছে।
- সব লিখিত প্রশ্নে উত্তর এবং CQ-র প্রতিটি অংশে solution আছে।
- সব `$...$` formula KaTeX-এ error ছাড়া render হয়েছে; Python string escape-এর control-character পরীক্ষা হয়েছে। এটি পূর্ণ browser/PDF layout proof নয়।
- পৃথক checker দিয়ে **নতুন ৪৮৯টি MCQ-এর সব উত্তর/অপশন** আবার গণনা; exact rational, set enumeration, Venn feasibility, irrational bounds এবং written-family symbolic identities পরীক্ষা পাস। এটি ১৫০ CQ/১১০ SQ-এর প্রতিটি বাক্যের স্বাধীন মানব-পর্যালোচনার বিকল্প নয়।
- সংশ্লিষ্ট ৬টি test suite-এ **৪২/৪২ test pass**, TypeScript typecheck ও `git diff --check` pass।

Reproduce (Python validation dependencies are dev-only, not app/runtime dependencies):

python3 -m pip install --target .cache/math-validation sympy==1.14.0
PYTHONPATH=.cache/math-validation python3 scripts/question-bank/build-ssc-math-targets.py --check

## ইমপোর্ট-অবস্থা

স্বাধীন শিক্ষক-পর্যালোচনা, authenticated live preview/save এবং actual import receipt বাকি। কোনো deployment, database write বা approved-stock দাবি করা হয়নি।
