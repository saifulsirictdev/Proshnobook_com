## কী দেওয়া হয়েছে

- প্রতি অধ্যায়ে ২টি সংকলন-অভিযোজিত উৎস MCQ + ১৪৮টি নিজস্ব MCQ, ৫০ CQ, ৭০ SQ। মোট **১২ source-adapted + ১৬০৮ original parameter variants**।
- Original MCQ/CQ/SQ family count **১৫/১০/১৪** প্রতি অধ্যায়ে। এগুলো ১৬২০টি স্বতন্ত্র ধারণা নয়; family-ভিত্তিক parameter practice।
- MCQ-তে বিকল্প/key/ব্যাখ্যা; CQ-তে ক/খ/গ, ২/৪/৪ ও অংশভিত্তিক সমাধান; SQ-তে সমাধান আছে। CQ-এর উপযোগিতা/marks-depth teacher review বাকি।
- ১৪–১৬ অধ্যায়ের সব প্রশ্নে নতুন schematic SVG; ১১–১৩ অধ্যায়ের বীজগাণিতিক প্রশ্নে অপ্রয়োজনীয় চিত্র জুড়ে দেওয়া হয়নি।
- ১৫তম অধ্যায়ে একই ভূমি/সমান্তরালের ক্ষেত্রফল উপপাদ্য, মধ্যমা, বিপরীত যুক্তি, কর্ণ, এবং ত্রিভুজ↔সামান্তরিক/আয়তক্ষেত্র ও চতুর্ভুজ→সমক্ষেত্র ত্রিভুজ নির্মাণের ধাপ ও যুক্তি আছে; শুধু সংখ্যাগত ক্ষেত্রফল অনুশীলনী নয়।
- ১৬তম অধ্যায়ে লম্ব উচ্চতা/তির্যক উচ্চতা, বক্রতল/সমগ্র পৃষ্ঠ, ঘন/বর্গ একক, সংযুক্ত নিরেট বস্তুর অভ্যন্তরীণ তল বাদ দেওয়ার পার্থক্য রক্ষিত। π প্রতীকেই রাখা হয়েছে।

## উৎসনীতি ও সীমা

প্রথমে আগে পাওয়া ২০২৪-লেবেলযুক্ত বোর্ড-সংকলনের ঢাকা PDF1, রাজশাহী PDF11, কুমিল্লা PDF20, বরিশাল PDF58 এবং দিনাজপুর PDF67-এর MCQ পাতা দৃশ্যত দেখা হয়েছে। প্রতিটি অধ্যায়ে নির্দিষ্ট দুটি যাচাইযোগ্য source seed ব্যবহার করা হয়েছে; বিকল্পের ক্রম রাখা হয়েছে, প্রয়োজনীয় সংজ্ঞা/শর্ত স্পষ্ট করে adaptation হিসেবে নথিবদ্ধ। এই উৎস স্বাধীনভাবে authenticated official paper নয়। বর্তমান NCTB-এর পূর্ণ অধ্যায় পাওয়া/পড়া হয়নি; বোর্ড অনুসন্ধান বা syllabus/concept coverage exhaustive নয়। পরবর্তী ১৬০৮টি নিজস্ব parameter practice, বোর্ড/NCTB-এর অবিকল হিসেবে দেখানো হয়নি।

Source safeguards: ১১-তে common proportional value শূন্য নয়; ১৪-তে rectangle-এর rotation প্রশ্নে “বর্গ নয়” ও “ক্ষুদ্রতম ধনাত্মক” স্পষ্ট; ১৬-তে cube-এর “কর্ণ” দিয়ে body diagonal বোঝানো স্পষ্ট। সংশোধিত গদ্যকে exact-board বলা হয়নি।

প্রতি অধ্যায়ের `README.md`-এ বিষয়পরিবার ও নির্দিষ্ট PDF/question নম্বর আছে। source/board UI default-off policy অপরিবর্তিত; searchable provenance সংরক্ষিত। কোনো নতুন board-search UI যোগ হয়নি।

## ফাইল ও ব্যবহার

- `content/question-bank/ssc/math/chapter-{11..16}/target-v1/{mcq,cq,sq}.json`: প্রতিটিতে ১৫০/৫০/৭০ প্রশ্ন—১৮টি strict importer slice।
- প্রতি chapter-এর manifest, validation/audit ও board-seed snapshot আলাদা আছে।
- `docs/question-bank/ssc-math-ch{chapter}-questions-v1-backup.json`: whole-chapter backup container; **সরাসরি importer input নয়**। `importFiles[].payload` অথবা ZIP-এর মূল slices ব্যবহার করতে হবে।
- `docs/question-bank/ssc-math-ch{chapter}-illustrated-review.html`: offline review, embedded Bengali/KaTeX fonts, expandable solutions; ১৪–১৬-তে inline SVG। Drive HTML preview না চললে download/open locally।
- প্রতি chapter ZIP ও সম্মিলিত ZIP-এ JSON, চিত্র, gallery, checks, README ও licenses আছে।
- Drive upload receipt-এ file IDs/size/MD5/SHA256 ও returned checksums মিলিয়ে রাখার তথ্য থাকবে।
