# Rearranging sentences — draft v002

50 sets: one directly based on Model Test 01 Q9 (printed p.3), 49 original practice scenarios. Each has eight shuffled parts, a suggested order and a full reconstructed story, following the model format. No original scenario claims historical attribution.

A number of scenarios share similar themes (notably notices, library books and gardens), and some may allow more than one coherent order. These require independent editorial and teacher review, along with source transcription, rights, age suitability and importer display. Count and structural checks do not certify semantic uniqueness or approval. No website import or publication.
