## Import করার নিয়ম
ZIP খুলুন। প্রতিটি `chapter-N` folder-এর `questions.json` আলাদাভাবে ব্যবহার করুন; ZIP সরাসরি uploader-এ দেবেন না।

ADMIN → `/admin/questions/import` → Class 6 → গণিত → সংশ্লিষ্ট অধ্যায় → JSON file upload → প্রিভিউ → সম্মতি → Pending সেভ। অথবা প্রস্তুত ব্যাচ কার্ড বেছে প্রিভিউ করুন।

- `questions.json`: বর্তমান uploader-compatible প্রশ্ন ও সমাধান।
- `review.md`: পড়ার উপযোগী প্রশ্ন ও সমাধান।
- `validation.json`: উৎসপাঠের প্রকৃত অবস্থা, family/variant ledger, গাণিতিক মান ও সীমাবদ্ধতা।

## কী যাচাই হয়েছে
সব ছয় JSON বাস্তব upload parser-এ পাস। প্রতি অধ্যায়ে ১০০/৩০/৩০, ১০০ MCQ-তে A/B/C/D সঠিক উত্তর ২৫টি করে, ভিন্ন চার অপশন, অনন্য exact stem এবং ২–৪–৪ CQ পরীক্ষা হয়েছে। Fraction-ভিত্তিক গণনা, scenario invariants, mean/median/mode checks ও deterministic regeneration পাস। সংশ্লিষ্ট ২৭টি পরীক্ষা এবং TypeScript check পাস। Import transaction tests mock-ভিত্তিক; production data ব্যবহার হয়নি।
