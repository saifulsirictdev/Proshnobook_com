## স্বাধীন শিক্ষক-পর্যালোচনার checklist
- [ ] অধ্যায় ১ মুদ্রিত ১–১০ সম্পূর্ণ পড়ে প্রশ্নের scope ও সংশোধন নথিবদ্ধ করা।
- [ ] প্রতিটি অধ্যায়ের উপবিষয়ের coverage matrix বানিয়ে অতিরিক্ত অনুশীলন/বাদ যাওয়া অংশ চিহ্নিত করা।
- [ ] ১৪০০ MCQ-র stem, একক সঠিক উত্তর, বিশ্বাসযোগ্য distractor, ভাষা ও জ্ঞানস্তর পর্যালোচনা।
- [ ] ৪২০ CQ-র উদ্দীপক, চার অংশের যোগসূত্র এবং ১/২/৩/৪ নম্বর অনুযায়ী উত্তর গভীরতা দেখা।
- [ ] ৪২০ SQ-র নির্ভুলতা, দৈর্ঘ্য ও পাঠ্যপুস্তক/বয়সোপযোগিতা দেখা।
- [ ] একই ধারণার অর্থগত পুনরাবৃত্তি কমিয়ে প্রয়োগের প্রকৃত বৈচিত্র্য বিচার। আলাদা stem ≠ আলাদা দক্ষতা।
- [ ] গণনা/একক/দিক, আদর্শ শর্ত ও বাস্তব সীমা পুনর্গণনা করা।
- [ ] বইয়ের অসংগতি/পুরোনো সাধারণীকরণ এবং সহায়ক সংশোধনের প্রমাণ ও বয়সোপযোগিতা যাচাই।
- [ ] বিশেষ করে খাদ্যজাল/বিয়োজক, লম্ব বলবাহু, ত্বরণের দিক, মহাবিস্ফোরণের মডেল ও আধুনিক বিলুপ্তি-ব্যাখ্যার স্তর যাচাই।
- [ ] পুষ্টি/স্বাস্থ্যের কোনো উত্তর ব্যক্তিগত রোগনির্ণয়, ওষুধ বা সম্পূরকের নির্দেশ হচ্ছে কি না দেখা।
- [ ] পরীক্ষা/মাঠকাজ/ভূমিকম্প/রাসায়নিক/তাপ/যন্ত্র ও বন্য প্রাণীর সব নিরাপত্তা যাচাই।
- [ ] নতুন চিত্র, টেবিল, যন্ত্রপাঠ বা পর্যবেক্ষণভিত্তিক প্রশ্ন প্রয়োজনমতো যুক্ত করা; বর্তমানে নতুন চিত্রভিত্তিক কভারেজ দাবি নেই।
- [ ] প্রতিটি প্রশ্নে নির্দিষ্ট পৃষ্ঠা ও provenance নির্ধারণ, পরিবর্তনের পর deterministic generator/পরীক্ষা পুনরায় চালানো।
- [ ] সংশোধিত JSON ও review Drive-এ নতুন সংস্করণে backup; আগের superseded ফাইল চিহ্নিত রাখা।
- [ ] ব্যবহারকারীকে পুরো বিষয়ের সংশোধিত প্যাকেট দিয়ে পর্যালোচনার সুযোগ দেওয়া। Pending জমার স্পষ্ট সিদ্ধান্ত ছাড়া import নয়।

## প্রযুক্তিগত পরীক্ষার অর্থ
৩৫ targeted ও ৭২২ full automated test পাস, Typecheck পাস। Parser/catalog/size, চার CQ অংশ/নম্বর, answer-key mapping, পৃথক option, হুবহু stem-অনন্যতা, whole-subject totals ও Draft gate যাচাই হয়। এগুলো বৈজ্ঞানিক সত্যতা বা স্বাধীন শিক্ষক অনুমোদনের বিকল্প নয়। Prepared registry স্থানীয় কোডে; live deployment বা database import নয়।

## Backup/সংস্করণ
Drive class→subject→chapter গঠন বজায়। অধ্যায় ১৩/১৪ current questions/validation/review v002; অধ্যায় ৮ current questions v003 (v002 বাতিল), validation/review v002। `drive-backup.json` current IDs ও আগের snapshot history রাখে। মূল বই PDF ZIP-এ নেই। পুরোনো ZIP filename compatibility-র জন্য আছে; বর্তমান manifest-এ সংখ্যা-পূর্ণ Draft লেখা।
