# ষষ্ঠ শ্রেণি বিজ্ঞান — ১৪ অধ্যায়ের অসম্পূর্ণ প্রাথমিক খসড়া

**এটি অনুরোধ করা সম্পূর্ণ প্রশ্নব্যাংক নয়।**

- প্রকৃত মোট: **২৩০ MCQ + ৪৭ CQ সেট + ৬৯ SQ = ৩৪৬ প্রশ্ন**।
- অধ্যায় ১: ১০০ MCQ, ৩০ CQ, ৩০ SQ—সংখ্যাগত ন্যূনতম লক্ষ্য পূর্ণ; শিক্ষক-যাচাই বাকি। অধ্যায় ২–৩: প্রতিটিতে ১০ MCQ, ৩ CQ, ৩ SQ। অধ্যায় ৪–১৪: প্রতিটিতে ১০ MCQ, ১ CQ, ৩ SQ।
- প্রতিটি CQ: ক/খ/গ/ঘ, নম্বর ১/২/৩/৪; প্রশ্ন ও উত্তর যুক্ত আছে।
- ন্যূনতম পুরো বইয়ের লক্ষ্য: ১৪০০ MCQ + ৪২০ CQ + ৪২০ SQ। **বাকি: ১১৭০ MCQ + ৩৭৩ CQ + ৩৫১ SQ।**
- কেবল নির্বাচিত পৃষ্ঠা দেখা হয়েছে; পূর্ণ অধ্যায় পড়া, প্রতিটি প্রশ্নের সুনির্দিষ্ট পৃষ্ঠা, চিত্রভিত্তিক কভারেজ, ভাষা ও স্বাধীন শিক্ষক যাচাই বাকি। নমুনা পৃষ্ঠা প্রতিটি অধ্যায়ের validation.json-এ আছে।
- পূর্ণ পাঠ্যসূচির কভারেজ বা শিক্ষক-অনুমোদন দাবি করা হচ্ছে না। স্বয়ংক্রিয় শব্দ/সংখ্যা বদলে কোটা পূরণ করা হয়নি।

## ফাইল
প্রতিটি chapter-N ফোল্ডারে:
- questions.json — বিদ্যমান uploader-এর schema অনুযায়ী প্রশ্ন ও উত্তর।
- review.md — সীমাবদ্ধতা ও পরবর্তী যাচাই।
- validation.json — প্রকৃত সংখ্যা, লক্ষ্য থেকে ঘাটতি, উৎসের নমুনা পৃষ্ঠা ও pending status। এটি বিষয়শিক্ষকের অনুমোদন নয়।

manifest.json-এ ১৪ অধ্যায়ের সংখ্যা একসঙ্গে আছে। উৎস PDF-এর SHA-256 প্রতিটি validation.json-এ আছে। বইয়ের কপি এই প্যাকেজে নেই।

## Import (শুধু Admin-এর আলাদা সিদ্ধান্তে)
https://proshnobook.com/admin/questions/import → Class 6 → বিজ্ঞান → সঠিক অধ্যায়। সংশ্লিষ্ট questions.json নির্বাচন করে Preview করতে হবে। পুরো ZIP uploader-এ দেওয়া যাবে না।

Prepared library-তে অধ্যায় ১-এর শিরোনামে “সংখ্যা পূর্ণ; শিক্ষক-যাচাই বাকি” এবং বাকি ১৩টির শিরোনামে “অসম্পূর্ণ Draft” থাকবে, এই কোড deploy হওয়ার পর। শিক্ষক-যাচাই ছাড়া এগুলোকে সম্পূর্ণ বা প্রকাশযোগ্য ধরে নেওয়া যাবে না। Save করলে বিদ্যমান নিয়মে Pending; এই কাজ থেকে কোনো production database import বা publication করা হয়নি।

## প্রযুক্তিগত যাচাই
- বাস্তব uploader parser, catalog match, চার CQ অংশ/নম্বর, distinct options, size cap ও deterministic regeneration পরীক্ষা পাস।
- উত্তরসূচির সঙ্গে লেখকের নির্ধারিত correct option মিলেছে; এই পরীক্ষা বৈজ্ঞানিক সত্যতা বা উপযুক্ত distractor-এর স্বাধীন যাচাই নয়।
- পূর্ব ধাপের Typecheck ও ২৫টি targeted test পাস হয়েছিল; সর্বশেষ সম্প্রসারণের ফল নিচের নোটে আছে। Prisma client type generation-এ dummy engine path ব্যবহৃত হয়েছে; database query নয়।

## অধ্যায় ১ সম্প্রসারণ
- ৯০ MCQ, ২৭টি সম্পূর্ণ CQ ও ২৭ SQ নতুন করে লেখা হয়েছে; স্বয়ংক্রিয় বাক্য/সংখ্যা বদলে তৈরি নয়।
- একক, দৈর্ঘ্য-পাঠ, ক্ষেত্রফল, নিয়মিত/অনিয়মিত আয়তন, ভর, সময়, পরীক্ষার পরিকল্পনা, তথ্য বিচার ও নিরাপত্তা নিয়ে প্রশ্ন আছে। এটি ১৬০টি স্বাধীন দক্ষতার দাবি নয়।
- পূর্ণ পাঠ্যবইয়ের সঙ্গে প্রতিটি প্রশ্নের scope, শব্দচয়ন, distractor ও CQ নম্বর অনুযায়ী উত্তর যাচাই বাকি। সবকিছু এখনো Draft।
- প্রযুক্তিগত লক্ষ্যপূরণ মানে শুধু ন্যূনতম প্রশ্নসংখ্যা পূরণ; শিক্ষক অনুমোদন বা প্রকাশের অনুমতি নয়।
- সর্বশেষ সম্প্রসারণের পরে: ১৯টি targeted test, Typecheck এবং পূর্ণ ৭০৬টি automated regression test পাস। এগুলো বিষয়শিক্ষকের অনুমোদন নয়।
